# Bethel Open Bible Church — Flutter

A **new, native Flutter app**, not the previous React Native or hand-packaged WebView APK.

## What was changed

- Removed the old native Android title/action bar completely. There is no `AppBar` in `BethelShell`.
- Refined custom Bethel header and dark navy/gold styling with the cross-and-Bible emblem.
- Built fully in Flutter/Dart for Android and iOS.
- Wired the church's supplied Facebook, Instagram and YouTube links.
- Added an offline rotating KJV verse of the day, read/reflection screen, scripture copy and persistent bookmarks.
- Added a private, on-device prayer journal with add/edit/delete and answered-prayer tracking.
- Added Messages and Events sections linking to verified church social channels rather than fictional recordings or schedules.
- Added fluid screen transitions and animated bottom navigation.

## How to get the APK

**This ZIP contains the source code, not a compiled APK.** The build environment that assembled this project does not include Flutter or Android SDKs. A real Flutter Android SDK build is required before installing.

### Option A: Windows

1. Install [Flutter for Windows](https://docs.flutter.dev/get-started/install/windows/mobile) and [Android Studio](https://developer.android.com/studio).
2. Run `flutter doctor` and follow its Android setup instructions (including SDK license acceptance).
3. Extract this ZIP and double-click `BUILD_ANDROID_APK_WINDOWS.bat`.
4. Once built, copy `build/app/outputs/flutter-apk/app-release.apk` to your phone.

### Option B: GitHub Actions (no local Flutter install)

1. Make a **private or public** GitHub repository and upload the **contents** of this project. Include the hidden `.github/workflows/build-android-apk.yml` file.
2. On GitHub, open **Actions → Build Bethel Android APK → Run workflow** (or push to `main`).
3. When the workflow succeeds, open its run and download the `Bethel-Open-Bible-Church-Flutter-APK` artifact ZIP.
4. Extract `app-release.apk` from the downloaded artifact and transfer it to your Samsung.

This workflow requires internet/build access and a GitHub account. It has not been run in this environment.

### Manual Flutter commands

```sh
flutter create --platforms=android --org org.bethelopenbible --project-name bethel_open_bible_church .
flutter pub get
dart run tool/configure_android.dart
dart run flutter_launcher_icons
flutter build apk --release
```

## Developer notes

- Package ID generated by Flutter will be `org.bethelopenbible.bethel_open_bible_church`, **different** from the old preview application. The old installation won't collide with the new one.
- The initial release build uses Flutter's default Android signing configuration for testing. Before public release, generate and securely retain a production release keystore; changing keys between builds prevents in-place updates. Do not commit keystores, passwords or secrets to GitHub.
- Build with a current Flutter stable SDK so that Flutter generates modern Android SDK/target settings.
- Local prayer entries and bookmarks can be erased on uninstall or clearing app data. No prayer content is uploaded to a server.
- The app does not include actual event dates, church address, online giving, or actual sermon list without verified church information.
- To customize text and social accounts, edit `lib/content.dart`. To customize interface, edit `lib/main.dart`.
- iOS builds require macOS with Xcode; `flutter create --platforms=ios .` can generate iOS files on a supported Mac.

## Test checklist after compilation

- App opens directly to the custom logo/header (no oversized gray text bar).
- Five nav tabs display and animate.
- `Today's scripture` opens the Word tab and changes with the local date.
- Bookmark a verse, close/reopen app: bookmark remains.
- Add a prayer, close/reopen app: journal entry remains; edit, mark answered and delete work.
- Three social buttons open the supplied official pages in a browser or app.
